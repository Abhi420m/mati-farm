# 🏺 Mati Farm™ — Artisanal Earthenware & Commercial Pottery

> **100% Organic, Wheel-Thrown Alluvial Terracotta Tableware, Sacred Diyas & Commercial Chai Kulhads**

Mati Farm is a completely standalone e-commerce and wholesale marketplace designed for:
1. **Direct-to-Consumer (D2C Retail):** Packaged retail packs (6, 12, 25 pcs) with an interactive cart, dynamic shipping tracker, promo coupons (`MATI10`, `EARTH50`), and a 2-step checkout flow.
2. **Enterprise Wholesale (B2B Hospitality):** Direct kiln-to-business volume tiers (500 to 25,000+ units), an institutional cost estimator, custom brand logo debossing, and freight calculators.
3. **Dual Currency Engine:** Real-time seamless toggle between **INR (₹)** and **USD ($)** for domestic and international export buyers.

---

## 🚀 Quick Start (Local Run)

### Method 1: One-Click Launcher
Double-click `start.bat` in this directory. It starts the server on port 4000 and automatically opens `http://localhost:4000/` in your browser.

### Method 2: Command Line
```bash
# Navigate to the mati-farm folder
cd mati-farm

# Start the standalone server
node server.js
```
Open **[http://localhost:4000/](http://localhost:4000/)** in your browser.

## ☁️ 1-Click Cloud Deployment

### 1. Deploy to Vercel (Free)
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this directory.
3. Choose defaults. Your site is live on a custom `.vercel.app` URL in 30 seconds!

### 2. Deploy to Netlify (Free)
1. Drag and drop the `mati-farm` folder to [Netlify Drop](https://app.netlify.com/drop).
2. Or connect your Git repository.

### 3. Deploy to Render / Railway / Cloudflare Pages
- **Build Command:** *(None required)*
- **Publish Directory:** `.` (root)
- **Start Command:** `node server.js`
